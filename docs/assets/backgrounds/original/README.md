# Kairos Background Originals

This folder is only for legally licensed full-size originals used as desktop-grade website backgrounds.

## Quality Rules

- Minimum: 5000px wide.
- Preferred: 7000px+ wide.
- Excellent: 8000px+ wide.
- Best tier: 9000px-12000px panoramas.
- Do not use 2048px web-size downloads for desktop backgrounds.
- Do not upscale low-resolution files and label them as originals.
- Do not use watermarked previews.
- Do not use paid-stock previews or scraped files.
- Preserve original JPEG/PNG quality; do not compress or overwrite originals here.
- Put future mobile/downscaled derivatives in `docs/assets/backgrounds/mobile/`, not this folder.

Run the local checker before wiring a file into the slideshow:

```sh
npm run check:backgrounds
```

`AdobeStock_240362026.jpeg` and `AdobeStock_537070829.jpeg` are retained here as licensed originals, but they are below the 5000px desktop-background minimum and should not be referenced by the desktop slideshow.

## Paid/Licensed Premium Options

- Adobe Stock: first stop for clean commercial cinematic backgrounds. Search for 9K-12K panoramas using `Tokyo skyline panorama`, `Mount Fuji panorama`, `Kawaguchiko panorama`, `Kyoto panorama`, `Japan night skyline`, `Tokyo Rainbow Bridge panorama`, and `Shibuya crossing night`.
- Getty/iStock: premium urban realism and city scenes. Prefer 7K-8K originals and check editorial-only restrictions.
- Alamy: long-tail backup for specific locations and unusual angles. Check exact pixel dimensions and model/property release notes.
- Direct photographers/500px/portfolio sites: best for authored medium-format style. License directly and confirm website/commercial usage rights.

## Free Source Notes

- Unsplash: usable for personal/commercial websites under the Unsplash License, but current public photo pages do not always expose original pixel dimensions and file size. Prefer pre-2017 CC0 Unsplash archives on Wikimedia Commons when strict verification is required.
- Pexels: usable under the Pexels license for personal/commercial use, but do not accept a file unless the original dimensions and file size are verified after legal download.
- Pixabay: usable under the Pixabay Content License; several Tokyo files list 5184-6000px widths. Verify downloaded original file size before use.
- Wikimedia Commons: best free source for auditable dimensions, file size, license, and attribution requirements.
- Flickr Creative Commons: only use files with a license that allows website use. Prefer files already reviewed on Wikimedia Commons, or verify the current Flickr license before use.
